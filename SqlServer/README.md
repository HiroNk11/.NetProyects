# Proyectos SQL Server

Proyectos de prueba de persistencia con SQL Server, acceso a datos y consultas sobre escenarios de gestion.

## Proyectos

1. `01-AgendaContactosSqlServer` - CRUD basico usando ADO.NET.
2. `02-PedidosSqlServer` - Scripts SQL de pedidos con tablas, datos iniciales, procedimientos almacenados, triggers y consultas de prueba.
