# Calculadora basica

Proyecto de prueba en evolucion.

Aplicacion de consola en C# que permite realizar operaciones matematicas simples.

## Funcionalidades

- Sumar dos numeros
- Restar dos numeros
- Multiplicar dos numeros
- Dividir dos numeros
- Validar que el usuario ingrese numeros
- Evitar division por cero
- Mostrar un menu interactivo

## Implementacion

- Variables
- Condicionales
- `switch`
- Ciclo `while`
- Metodos
- Validacion con `double.TryParse`
