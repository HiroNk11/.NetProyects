# Registro de ventas

Proyecto de prueba en evolucion.

Aplicacion de consola en C# para registrar ventas con varios productos y calcular totales.

## Funcionalidades

- Registrar ventas
- Agregar varios productos por venta
- Calcular subtotales por producto
- Calcular total por venta
- Listar ventas registradas
- Ver detalle de una venta
- Calcular total vendido

## Implementacion

- Clases relacionadas
- `List<T>`
- Composicion de objetos
- `decimal` para importes
- `DateTime`
- `Sum`
- `FirstOrDefault`
- Validaciones
