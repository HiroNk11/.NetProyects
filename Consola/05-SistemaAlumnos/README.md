# Sistema de alumnos

Proyecto de prueba en evolucion.

Aplicacion de consola en C# para administrar alumnos, cargar notas y calcular promedios.

## Funcionalidades

- Agregar alumnos con legajo, nombre y apellido
- Evitar legajos repetidos
- Listar alumnos cargados
- Agregar notas entre 0 y 10
- Calcular promedio
- Mostrar estado academico
- Buscar alumnos por legajo

## Implementacion

- Clases y objetos
- Propiedades
- `List<T>`
- Metodos
- `foreach`
- `FirstOrDefault`
- `Average`
- Validaciones con `int.TryParse` y `double.TryParse`
