# Adivinar numero

Proyecto de prueba en evolucion.

Juego de consola en C# donde el usuario debe adivinar un numero secreto generado aleatoriamente.

## Funcionalidades

- Generar un numero aleatorio entre 1 y 100
- Permitir hasta 7 intentos
- Indicar si el numero secreto es mayor o menor
- Validar numeros enteros
- Validar que el numero este dentro del rango permitido
- Permitir jugar otra partida

## Implementacion

- Clase `Random`
- Constantes
- Ciclo `for`
- Ciclo `do while`
- Condicionales
- Metodos
- Validacion con `int.TryParse`
