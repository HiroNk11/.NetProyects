# Sistema de reservas de hotel

Proyecto de prueba en evolucion.

Aplicacion de consola en C# para administrar reservas simples de habitaciones de hotel.

## Funcionalidades

- Crear reservas
- Listar habitaciones
- Listar reservas
- Buscar reservas por cliente
- Cancelar reservas
- Validar fechas de ingreso y salida
- Verificar disponibilidad de habitaciones
- Calcular noches y total de la estadia

## Implementacion

- Clases relacionadas
- `List<T>`
- `DateTime`
- `DateTime.TryParseExact`
- Validacion de rangos de fechas
- Busquedas con LINQ
- Reglas de negocio
