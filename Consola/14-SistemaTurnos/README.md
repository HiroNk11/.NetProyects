# Sistema de turnos

Proyecto de prueba en evolucion.

Aplicacion de consola en C# para agendar y administrar turnos simples.

## Funcionalidades

- Agendar turnos
- Listar turnos ordenados por fecha
- Buscar turnos por paciente
- Cancelar turnos
- Evitar turnos duplicados para un profesional
- Validar fechas futuras

## Implementacion

- `DateTime`
- `DateTime.TryParseExact`
- `List<T>`
- `Any`
- `Where`
- `OrderBy`
- Encapsulamiento simple
- Reglas de negocio
