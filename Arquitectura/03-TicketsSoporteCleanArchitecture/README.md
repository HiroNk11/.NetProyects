# 03 - Tickets Soporte Clean Architecture

Aplicacion de consola para gestionar tickets de soporte con estados y prioridades.

## Funcionalidades

- Crear tickets.
- Asignar tecnico.
- Cambiar estado.
- Listar tickets abiertos.
- Listar tickets por prioridad.

## Buenas practicas aplicadas

- Entidad con reglas de cambio de estado.
- Servicio de aplicacion para casos de uso.
- Repositorio abstraido por interfaz.
- Presentacion separada del dominio.
