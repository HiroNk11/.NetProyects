# Agenda de contactos WinForms MVC

Proyecto de prueba en evolucion.

Aplicacion Windows Forms para administrar contactos aplicando separacion de responsabilidades.

## Funcionalidades

- Alta de contactos
- Edicion de contactos
- Eliminacion de contactos
- Busqueda por nombre
- Validaciones de campos
- Grilla de resultados

## Buenas practicas aplicadas

- Modelo `Contacto`
- Controlador `ContactoController`
- Repositorio con interfaz `IContactoRepository`
- Validador separado
- Formulario enfocado en la interfaz grafica
