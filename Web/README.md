# Aplicaciones web

Proyectos de prueba que integran interfaz, reglas de negocio, autenticacion, persistencia y pruebas automatizadas.

## Proyectos

1. [Mesa de ayuda](01-MesaAyuda/README.md): gestion de tickets con ASP.NET Core MVC, Identity, EF Core y SQLite. Incluye roles, comentarios, historial, filtros y pruebas de integracion HTTP.

Estos proyectos usan .NET moderno; los proyectos de la carpeta `WebApi/` conservan su implementacion con .NET Framework 4.8.
