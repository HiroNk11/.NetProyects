# Configuracion AppConfig

Proyecto de prueba en evolucion.

Aplicacion de consola que lee valores desde `App.config`.

## Valores configurados

- Nombre de aplicacion
- Maximo de intentos de login
- Modo mantenimiento
- Email de soporte

## Buenas practicas aplicadas

- Evitar valores fijos dentro del codigo.
- Centralizar configuracion en un archivo externo.
- Convertir valores con validacion y defaults.
