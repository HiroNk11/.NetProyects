# 01 - Logger Archivos

Aplicacion de consola que muestra como registrar mensajes en consola y archivo usando una interfaz comun.

## Funcionalidades

- Registrar mensajes informativos.
- Registrar advertencias.
- Registrar errores.
- Combinar varios loggers con `CompositeLogger`.

## Buenas practicas aplicadas

- Inversion de dependencias con `ILogger`.
- Separacion entre servicio de negocio y salida de logs.
- Creacion automatica de carpeta de logs.
